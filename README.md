# anti-slop-plugin

A Claude plugin marketplace with one plugin, `anti-slop`: a chat-ready skill for removing AI-writing tells from text.

Adapted from [kjmagnan1s/anti-slop](https://github.com/kjmagnan1s/anti-slop) (MIT; Wikipedia "Signs of AI writing" lineage material is CC BY-SA). See `plugins/anti-slop/skills/anti-slop/LICENSE` and `CREDITS.md`.

Add it in Claude: Customize > Plugins > Add > Add marketplace > `Realchrisbitar/anti-slop-plugin`, then install `anti-slop`.
